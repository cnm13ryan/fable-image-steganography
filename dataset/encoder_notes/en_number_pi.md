Carrier: the number of lit window rows (dashed `<line>` elements) in each skyline building, plus the number of stacked container rects in each stack of the container yard.

How to read it: Each building in the skyline group encodes one letter, where the count of window lines inside the building (equivalently, its height minus 4, divided by 9) gives the letter's alphabet position with A=1 through Z=26. Buildings are read left to right, and the four nested `<g>` blocks, which are also separated by wider gaps on the x axis, mark the word boundaries. The yard group then supplies the numeric part: each `<g>` stack is one digit, equal to the number of container rects it contains, read left to right. Skyline is read first, yard second, following the top-to-bottom order of the scene.
